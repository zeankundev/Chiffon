# Chiffon
A minimal, Unix-like **monolithic kernel with an IPC layer (hybrid goal pending)** + operating system for x86_64 and aarch64.

## Building
```
make run # Standard boot, if you want to run it as a standard UART console
make run-gfx # Boot + spin up graphics
```

## Contributing with AI
