# P3 integrated hybrid boundary

## Audit scope

The integrated source at `aecac31` includes the loader and HID isolation changes, the core storage and network work, and subsequent process and syscall changes. The [placement manifest](MANIFEST.md) accounts for all 83 tracked files under arch, drivers, kernel, include and userland. The Makefile also links board implementations from device/ and embeds service executables built separately from kernel objects.

## Ownership and failure paths

| Path | Source-level boundary |
| --- | --- |
| Boot, VM, processes and IPC | Architecture entry and exception code call the kernel dispatcher. The kernel owns PMM/VMM, scheduler, process lifetime, IPC port ownership and hardware capability checks. The boot loader launches privileged children from embedded images. |
| Storage | The root block layer selects a bounded disk extent and calls an in-kernel filesystem mount callback. VFS reads call the filesystem directly. The persistence log uses the board block transport. x86 removable USB mass storage reaches the kernel FAT reader through the bulk transport. |
| Network | Kernel socket calls and protocol processing reach trusted NIC callbacks directly. Packet processing and buffers stay in kernel space. |
| Display | The boot console, primary framebuffer backend and VT remain available independently of the user framebuffer process. The loader can start a fresh framebuffer process with a new service port and a framebuffer-scoped mapping. |
| Input and USB | The kernel owns primary PS/2 and virtio input, TTY routing, USB attachment generations and the x86 xHCI controller. The HID service parses report descriptors and decodes keyboard and mouse packets. Its kernel port validates device authority and bounded transactions. Exit clears held USB input state. AArch64 exercises the service lifecycle and uses virtio for its primary keyboard. |
| DMA | PCI bus mastering, endpoint configuration and DMA buffers stay with trusted kernel transport code. User HID processing gets copied records. The framebuffer grant supplies framebuffer pages. Deployment requires trusted DMA devices and host backends. |

The two user servers communicate through IPC. Port closure returns `-EPIPE` to blocked callers and stale handles. Restart creates a new service instance. These process-level guarantees coexist with kernel-owned device transports and the trusted-device assumption. Kernel-side transport or firmware failures remain outside the service-crash tests.

## Integrated build repair

At the audit revision, the x86_64 target built and the AArch64 compile stopped on 16 syscall dispatcher names introduced by later commits. Thirteen have native asm-generic numbers, now declared in the AArch64 table. Three legacy path-based calls (link, chown and lchown) belong with the existing x86 legacy dispatch cases. The AArch64 paths use linkat and fchownat. The patch preserves the other syscall handlers and the public Chiffon service ABI.

## Verification

Both targets built from the audit revision with this repair using the Demo full profile, GCC `-Werror` for kernel and userland, QEMU board and ext4. Both passed the release boot suite, HID lifecycle suite, gateway network smoke and three-boot persistence test. The x86 HID test additionally exercised xHCI input, unplug/replug and service restart. The source-level ownership decisions apply to both architectures; the QEMU checks establish only the configurations exercised.

From the checkout with the built images, use the release runners with the following arguments for each architecture. Use a fresh evidence directory.

```sh
set -eu
for arch in x86_64 aarch64; do
    images="build/demo/$arch-qemu"
    output="evidence/$arch"
    mkdir -p "$output"
    python3 -B tools/release/boot_smoke.py "$arch" "$images/chiffon.bin" "$images/disk.img" "$output/boot"
    python3 -B tools/release/hid_service.py "$arch" "$images/chiffon.bin" "$images/disk.img" "$output/hid.log"
    python3 -B tools/release/network_smoke.py "$arch" "$images" >"$output/network.log"
    python3 -B tools/release/storage_smoke.py "$arch" "$images" "$output/storage"
done
```
