# P1 modular driver contract

## Identity and launch

The boot path selects the embedded loader. Its forked child can exec the embedded framebuffer server. The kernel chooses those images independently of writable filesystem contents. The loader grants framebuffer pages to its live child with an unshared address space, followed by service registration authority. An unrelated process cannot signal the loader's bootstrap child or the framebuffer server during the interval before its first grant.

## ABI and ownership

Driver ABI version 2 adds the deny-only `CHI_CAP_DMA` type. Existing numbers, structures and accepted grants retain their ABI. No device currently has a user DMA domain. The controller, bus-master registers, descriptors and DMA buffers stay kernel-owned. An extension requiring DMA must submit bounded work through a trusted transport. The framebuffer grant covers only its cataloged page-aligned extent. The loader cannot delegate its own authority or grant an IRQ for this device. IRQ wait requires both a matching grant and a live claim. Driver exit discards grants and releases claims.

## Messages and failure

The kernel checks the name or full fixed-size message buffer and enforces `IPC_DATA_MAX` before dispatch. Receive and call validate writable output again after sleeping. The server alone can receive on its port and reply to pending calls. The loader, console and framebuffer names have separate registration checks. Port teardown wakes waiting callers with `-EPIPE`. Restart requires fresh grants and a new port lookup.

## Repeatable verification

Run the P0 procedure using this revision. Both Demo architectures built with warnings as errors and passed the QEMU boot smoke runner, including the guest `/bin/cap-probe` which checks unprivileged grants, reserved registration, MMIO and IRQ authority, IPC message length and invalid buffer rejection. This probe covers denial for ordinary user processes. It does not exercise physical IRQ delivery, DMA domain isolation or board hardware. The broader ROADMAP privilege and ownership audits remain open.
