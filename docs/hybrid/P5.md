# P5 final review

## Reviewed revision and scope

The tested source is `5c734aaa46142a2b2dd6710ccd7089bc79898474`. The final qualification used committed bytes from a fresh Git archive, separate full-profile Demo builds and isolated writable test disks. The optional BIOS ISO used its own build directory to keep its initramfs separate from the ext4 root images. This phase adds the qualification record to the repository.

## Architecture and compatibility

The final diff retains the kernel-owned storage, VFS, network, primary console, interrupt and process paths documented by [P3](P3.md). The framebuffer and HID service executables run as user processes. The trusted x86 transport retains the bus master, queues, config descriptors and removable-storage endpoint. The user HID server receives bounded reports over IPC. The additive v2/v3 definitions preserve the checked v1 values and layouts on both targets. Subsequent syscall additions from the integrated branch were retained.

## Evidence and limitations

All final compiler, guest, host-fixture and ISO outcomes and the artifact hashes appear in [release evidence](../RELEASE_EVIDENCE.md). Whole-disk and MBR durability runs interrupted QEMU after a successful sync. They establish replay for that sequence. DMA confinement, a full user-pointer audit, positive IRQ delegation, power loss during outstanding I/O, physical hardware qualification and SMP stress remain open. The broader ROADMAP checkboxes stay open for these items. The supported security scope continues to require trusted devices and backends.
