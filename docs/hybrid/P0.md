Testing a clean archive preserved the tracked bytes and passed. The HID parser probe exercises software parsing; keyboard device events require separate testing.

## Repeat the baseline

On an x86_64 Linux host install GCC, AArch64 GNU cross GCC/binutils, make, e2fsprogs, Python 3 and both QEMU system emulators. Use an empty scratch directory for the export. Run the following from the repository root.

```sh
set -eu
scratch=$(mktemp -d)
git archive b57e409b0489893f1923c485e1605868be047883 | tar -x -C "$scratch"
cd "$scratch"
for arch in x86_64 aarch64; do
    compiler=gcc
    if [ "$arch" = aarch64 ]; then compiler=aarch64-linux-gnu-gcc; fi
    make -j8 ENV=demo ARCH="$arch" DEVICE=qemu CC="$compiler -Werror" UCC="$compiler -Werror" >"$arch-build.log" 2>&1
    images="build/demo/$arch-qemu"
    python3 tools/release/boot_smoke.py "$arch" "$images/chiffon.bin" "$images/disk.img" "result-$arch"
done
```

These baseline checks cover QEMU. Device hotplug, driver crash/restart, direct keyboard delivery, persistence across boots and physical hardware have separate release gates.
