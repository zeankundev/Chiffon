# P4 integration and resilience

## Architecture and scope

The core owns boot, memory, process scheduling, interrupts, IPC and capabilities. Core storage, VFS, network, primary input and console retain direct kernel paths. Isolated display and USB HID processes receive device-specific authority. The HID path copies bounded data across IPC and keeps DMA descriptors, controller state and removable storage in the kernel. [Audited placement](MANIFEST.md)

## Reproduce the integration checks

Use a clean Linux Git export as in P0, substituting the revision to test. Run the following from that export. The evidence directory must be fresh.

```sh
set -eu
for arch in x86_64 aarch64; do
    compiler=gcc
    if [ "$arch" = aarch64 ]; then compiler=aarch64-linux-gnu-gcc; fi
    out="evidence/$arch"
    mkdir -p "$out"
    make -j8 ENV=demo ARCH="$arch" DEVICE=qemu CC="$compiler -Werror" UCC="$compiler -Werror" >"$out/build.log" 2>&1
    img="build/demo/$arch-qemu"
    python3 -B tools/release/boot_smoke.py "$arch" "$img/chiffon.bin" "$img/disk.img" "$out/boot"
    python3 -B tools/release/hid_service.py "$arch" "$img/chiffon.bin" "$img/disk.img" "$out/primary.log" --primary
    python3 -B tools/release/hid_service.py "$arch" "$img/chiffon.bin" "$img/disk.img" "$out/hid.log"
    python3 -B tools/release/network_smoke.py "$arch" "$img" >"$out/network.log"
    python3 -B tools/release/storage_smoke.py "$arch" "$img" "$out/storage"
done
```

## Coverage

Boot smoke checks loader status, benchmark completion, framebuffer startup, console and framebuffer IPC, three echo replies and the four release probes. The primary keyboard test sends Ctrl-C using QMP and requires four ordered key records from tty0 and a surviving reader. A fresh process verifies restoration to TTY mode. The HID suite checks server restart on both boards and USB keyboard/mouse handling and reattachment on x86_64. The network and storage runners exercise framebuffer crash recovery while their core subsystems remain operational. The storage runner uses a temporary writable disk and verifies contents after both orderly shutdown and interruption following sync.
